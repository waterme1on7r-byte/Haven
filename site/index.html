Haven playback controls

Open local audio, move through a waveform, and keep track details close to the player.

See the supported formats

  1. Haven file import

    Open audio files or a folder, or drop them into Haven to build the playlist.

  2. Haven waveform seeking

    Click or drag the waveform to move through a track; use the ring to seek too.

  3. Haven track metadata card

    Hover over the player for a metadata card. It fades after three seconds.

Gapless playback in Haven

At a track’s end, the decoder opens the next file and writes to the same audio ring. The stream is rebuilt only when its sample rate changes.

Built with Rust and egui, using Symphonia to decode audio and cpal for output.
